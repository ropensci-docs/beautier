# Determine if x is an initialized exponential distribution object as created by [`create_exp_distr`](https://docs.ropensci.org/beautier/reference/create_exp_distr.md)

Determine if x is an initialized exponential distribution object as
created by
[`create_exp_distr`](https://docs.ropensci.org/beautier/reference/create_exp_distr.md)

## Usage

``` r
is_init_exp_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized exponential distribution
  object

## Value

TRUE if x is an initialized exponential distribution object
