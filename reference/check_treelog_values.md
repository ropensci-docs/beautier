# Check if the treelog has the list elements with valid values for being a valid treelog object.

Calls `stop` if a value is invalid

## Usage

``` r
check_treelog_values(treelog)
```

## Arguments

- treelog:

  a `treelog`, as created by
  [create_treelog](https://docs.ropensci.org/beautier/reference/create_treelog.md)

## Value

nothing

## See also

Use
[create_treelog](https://docs.ropensci.org/beautier/reference/create_treelog.md)
to create a valid treelog
