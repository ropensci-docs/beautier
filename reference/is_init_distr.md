# Determine if x is an initialized distribution object as created by [`create_distr`](https://docs.ropensci.org/beautier/reference/create_distr.md)

Determine if x is an initialized distribution object as created by
[`create_distr`](https://docs.ropensci.org/beautier/reference/create_distr.md)

## Usage

``` r
is_init_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized distribution object

## Value

TRUE if x is an initialized distribution object
