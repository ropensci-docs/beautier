# Create a filename for a temporary \`screenlog\` file

Create a filename for a temporary \`screenlog\` file

## Usage

``` r
create_temp_screenlog_filename()
```

## Value

a filename for a temporary \`screenlog\` file

## See also

use
[create_screenlog](https://docs.ropensci.org/beautier/reference/create_screenlog.md)
to create a screenlog.

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
check_empty_beautier_folder()

create_temp_screenlog_filename()
#> [1] "/github/home/.cache/beautier/screenlog_5d23415bd0b.csv"

check_empty_beautier_folder()
```
