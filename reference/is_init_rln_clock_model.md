# Determine if x is an initialized relaxed log-normal clock_model object

Determine if x is an initialized relaxed log-normal clock_model object

## Usage

``` r
is_init_rln_clock_model(rln_clock_model)
```

## Arguments

- rln_clock_model:

  a Relaxed Log-Normal clock model, as returned by
  [`create_rln_clock_model`](https://docs.ropensci.org/beautier/reference/create_rln_clock_model.md)

## Value

TRUE if x is an initialized relaxed log-normal clock_model object, FALSE
otherwise
