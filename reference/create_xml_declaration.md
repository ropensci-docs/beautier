# Create the XML declaration of the BEAST2 XML input file

Create the XML declaration of the BEAST2 XML input file

## Usage

``` r
create_xml_declaration()
```

## Value

one line of XML text

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
check_empty_beautier_folder()

create_xml_declaration()
#> [1] "<?xml version=\"1.0\" encoding=\"UTF-8\" standalone=\"no\"?>"

check_empty_beautier_folder()
```
