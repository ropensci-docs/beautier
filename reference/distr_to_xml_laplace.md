# Internal function

Converts a Laplace distribution to XML

## Usage

``` r
distr_to_xml_laplace(distr, beauti_options)
```

## Arguments

- distr:

  a Laplace distribution as created by
  [`create_laplace_distr`](https://docs.ropensci.org/beautier/reference/create_laplace_distr.md))

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

the distribution as XML text
