# Converts a gamma site model to XML, used in the `state` section

Converts a gamma site model to XML, used in the `state` section

## Usage

``` r
gamma_site_model_to_xml_state(gamma_site_model, id)
```

## Arguments

- gamma_site_model:

  a gamma site model, as created by
  [`create_gamma_site_model`](https://docs.ropensci.org/beautier/reference/create_gamma_site_model.md))

- id:

  the site model's ID

## Value

the gamma_site model as XML text
