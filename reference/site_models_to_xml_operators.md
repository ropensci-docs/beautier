# Write the XML `operators` section from the site models.

Write the XML `operators` section from the site models.

## Usage

``` r
site_models_to_xml_operators(site_models)
```

## Arguments

- site_models:

  one or more site models, as returned by
  [`create_site_model`](https://docs.ropensci.org/beautier/reference/create_site_model.md)

## Value

lines of XML text
