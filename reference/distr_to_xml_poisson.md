# Internal function

Converts a Poisson distribution to XML

## Usage

``` r
distr_to_xml_poisson(distr, beauti_options)
```

## Arguments

- distr:

  a Poisson distribution, as created by
  [`create_poisson_distr`](https://docs.ropensci.org/beautier/reference/create_poisson_distr.md))

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

the distribution as XML text
