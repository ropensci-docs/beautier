# Determine if x is an initialized Poisson distribution object as created by [`create_poisson_distr`](https://docs.ropensci.org/beautier/reference/create_poisson_distr.md)

Determine if x is an initialized Poisson distribution object as created
by
[`create_poisson_distr`](https://docs.ropensci.org/beautier/reference/create_poisson_distr.md)

## Usage

``` r
is_init_poisson_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized Poisson distribution
  object

## Value

TRUE if x is an initialized Poisson distribution object
