# Determine if x is an initialized Laplace distribution as created by [`create_laplace_distr`](https://docs.ropensci.org/beautier/reference/create_laplace_distr.md)

Determine if x is an initialized Laplace distribution as created by
[`create_laplace_distr`](https://docs.ropensci.org/beautier/reference/create_laplace_distr.md)

## Usage

``` r
is_init_laplace_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized Laplace distribution

## Value

TRUE if x is an initialized Laplace distribution
