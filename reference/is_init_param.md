# Determine if x is an initialized parameter, as created by [create_param](https://docs.ropensci.org/beautier/reference/create_param.md)

Determine if x is an initialized parameter, as created by
[create_param](https://docs.ropensci.org/beautier/reference/create_param.md)

## Usage

``` r
is_init_param(x)
```

## Arguments

- x:

  the object to check if it is an initialized parameter

## Value

[TRUE](https://rdrr.io/r/base/logical.html) if x is an initialized
parameter, [FALSE](https://rdrr.io/r/base/logical.html) otherwise
