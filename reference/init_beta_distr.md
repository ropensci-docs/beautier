# Initializes a beta distribution

Initializes a beta distribution

## Usage

``` r
init_beta_distr(beta_distr, distr_id = 0, param_id = 0)
```

## Arguments

- beta_distr:

  a beta distribution, using
  [create_beta_distr](https://docs.ropensci.org/beautier/reference/create_beta_distr.md)

- distr_id:

  the first distribution's ID

- param_id:

  the first parameter's ID

## Value

an initialized beta distribution
