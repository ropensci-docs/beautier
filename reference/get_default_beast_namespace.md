# Get the default \`namespace\` element value of the \`beast\` XML tag.

Get the default \`namespace\` element value of the \`beast\` XML tag.

## Usage

``` r
get_default_beast_namespace()
```

## Value

the default \`namespace\` element value of the \`beast\` XML tag.
