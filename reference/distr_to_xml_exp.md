# Internal function

Converts an exponential distribution to XML

## Usage

``` r
distr_to_xml_exp(distr, beauti_options)
```

## Arguments

- distr:

  an exponential distribution, as created by
  [`create_exp_distr`](https://docs.ropensci.org/beautier/reference/create_exp_distr.md))

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

the distribution as XML text
