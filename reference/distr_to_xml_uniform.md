# Internal function

Converts a uniform distribution to XML

## Usage

``` r
distr_to_xml_uniform(distr, beauti_options)
```

## Arguments

- distr:

  a uniform distribution, as created by
  [`create_uniform_distr`](https://docs.ropensci.org/beautier/reference/create_uniform_distr.md))

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

the distribution as XML text
