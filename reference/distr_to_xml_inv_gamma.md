# Internal function

Converts an inverse-gamma distribution to XML

## Usage

``` r
distr_to_xml_inv_gamma(distr, beauti_options)
```

## Arguments

- distr:

  an inverse-gamma distribution, as created by
  [`create_inv_gamma_distr`](https://docs.ropensci.org/beautier/reference/create_inv_gamma_distr.md))

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

the distribution as XML text
