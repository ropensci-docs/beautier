# Creates the map section of a BEAST2 XML parameter file

Creates the map section of a BEAST2 XML parameter file

## Usage

``` r
create_beast2_input_map(beauti_options)
```

## Arguments

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

lines of XML text
