# Determine if x is an initialized Coalescent Constant Population tree_prior object

Determine if x is an initialized Coalescent Constant Population
tree_prior object

## Usage

``` r
is_init_ccp_tree_prior(x)
```

## Arguments

- x:

  the object to check if it is an initialized Coalescent Constant
  Population tree prior object

## Value

TRUE if x is an initialized Coalescent Constant Population tree prior
object
