# Determine if x is an initialized site model, as created by [`create_site_model`](https://docs.ropensci.org/beautier/reference/create_site_model.md)

Determine if x is an initialized site model, as created by
[`create_site_model`](https://docs.ropensci.org/beautier/reference/create_site_model.md)

## Usage

``` r
is_init_site_model(x)
```

## Arguments

- x:

  the object to check if it is an initialized site_models object

## Value

TRUE if x is an initialized site model
