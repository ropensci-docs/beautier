# Initializes a Birth-Death tree prior

Initializes a Birth-Death tree prior

## Usage

``` r
init_bd_tree_prior(bd_tree_prior, distr_id, param_id)
```

## Arguments

- bd_tree_prior:

  a Birth-Death tree prior, as created by
  [`create_bd_tree_prior`](https://docs.ropensci.org/beautier/reference/create_bd_tree_prior.md)

- distr_id:

  a distributions' ID

- param_id:

  a parameter's ID

## Value

an initialized Birth-Death tree prior
