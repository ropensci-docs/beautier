# See if x is one MRCA prior with a distribution

See if x is one MRCA prior with a distribution

## Usage

``` r
is_mrca_prior_with_distr(x)
```

## Arguments

- x:

  the object to be tested

## Value

TRUE if x is one MRCA prior with a distribution, FALSE otherwise
