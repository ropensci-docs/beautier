# Indent text for a certain number of spaces. If the text is only whitespace, leave it as such

Indent text for a certain number of spaces. If the text is only
whitespace, leave it as such

## Usage

``` r
indent(text, n_spaces = 4)
```

## Arguments

- text:

  the text to indent

- n_spaces:

  the number of spaces to add before the text. BEAUti uses four spaces
  by default

## Value

the indented text
