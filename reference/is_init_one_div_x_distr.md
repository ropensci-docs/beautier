# Determine if x is an initialized one_div_x distribution object as created by [`create_one_div_x_distr`](https://docs.ropensci.org/beautier/reference/create_one_div_x_distr.md)

Determine if x is an initialized one_div_x distribution object as
created by
[`create_one_div_x_distr`](https://docs.ropensci.org/beautier/reference/create_one_div_x_distr.md)

## Usage

``` r
is_init_one_div_x_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized one_div_x distribution
  object

## Value

TRUE if x is an initialized one_div_x distribution object
