# Check if the `tn93_site_model` has the list elements of a valid `tn93_site_model` object.

Calls `stop` if an element is missing

## Usage

``` r
check_tn93_site_model_names(tn93_site_model)
```

## Arguments

- tn93_site_model:

  a TN93 site model, as returned by
  [`create_tn93_site_model`](https://docs.ropensci.org/beautier/reference/create_tn93_site_model.md)

## Value

nothing

## See also

Use
[create_tn93_site_model](https://docs.ropensci.org/beautier/reference/create_tn93_site_model.md)
to create a valid `tn93_site_model`
