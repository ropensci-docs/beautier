# Initializes a parameter

Initializes a parameter

## Usage

``` r
init_param(param, id)
```

## Arguments

- param:

  a parameter, using
  [`create_param`](https://docs.ropensci.org/beautier/reference/create_param.md)

- id:

  the parameter's ID. Will be ignored if the parameter already has an ID

## Value

an initialized parameter
