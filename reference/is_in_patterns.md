# Is there at least one regular expression having a match with the line?

Is there at least one regular expression having a match with the line?

## Usage

``` r
is_in_patterns(line, patterns)
```

## Arguments

- line:

  a line of text

- patterns:

  one or more regular expression patterns

## Value

TRUE if there is at least one match found
