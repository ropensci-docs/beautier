# Check if a `tracelog` is valid.

Will call [stop](https://rdrr.io/r/base/stop.html) if not.

## Usage

``` r
check_tracelog(tracelog)
```

## Arguments

- tracelog:

  a `tracelog`, as created by
  [create_tracelog](https://docs.ropensci.org/beautier/reference/create_tracelog.md)

## Value

No return value, called for side effects
