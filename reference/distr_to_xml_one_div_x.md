# Internal function

Converts a 1/x distribution to XML

## Usage

``` r
distr_to_xml_one_div_x(distr, beauti_options)
```

## Arguments

- distr:

  a 1/x distribution, as created by
  [`create_one_div_x_distr`](https://docs.ropensci.org/beautier/reference/create_one_div_x_distr.md))

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

the distribution as XML text
