# Check if the MRCA prior, which is a list, has all the named elements.

Calls `stop` if not.

## Usage

``` r
check_mrca_prior_names(mrca_prior)
```

## Arguments

- mrca_prior:

  a Most Recent Common Ancestor prior, as returned by
  [`create_mrca_prior`](https://docs.ropensci.org/beautier/reference/create_mrca_prior.md)

## Value

nothing

## See also

Use
[check_mrca_prior](https://docs.ropensci.org/beautier/reference/check_mrca_prior.md)
to check the entire MRCA prior
