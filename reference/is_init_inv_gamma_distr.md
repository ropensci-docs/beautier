# Determine if x is an initialized inverse-gamma distribution as created by [`create_inv_gamma_distr`](https://docs.ropensci.org/beautier/reference/create_inv_gamma_distr.md)

Determine if x is an initialized inverse-gamma distribution as created
by
[`create_inv_gamma_distr`](https://docs.ropensci.org/beautier/reference/create_inv_gamma_distr.md)

## Usage

``` r
is_init_inv_gamma_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized inverse-gamma distribution

## Value

TRUE if x is an initialized inverse-gamma distribution
