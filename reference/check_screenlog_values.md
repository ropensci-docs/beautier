# Check if the screenlog has the list elements with valid values for being a valid screenlog object.

Calls `stop` if a value is invalid

## Usage

``` r
check_screenlog_values(screenlog)
```

## Arguments

- screenlog:

  a `screenlog`, as created by
  [create_screenlog](https://docs.ropensci.org/beautier/reference/create_screenlog.md)

## Value

nothing

## See also

Use
[create_screenlog](https://docs.ropensci.org/beautier/reference/create_screenlog.md)
to create a valid screenlog
