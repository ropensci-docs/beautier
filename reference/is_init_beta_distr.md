# Determine if x is an initialized beta distribution object as created by [`create_beta_distr`](https://docs.ropensci.org/beautier/reference/create_beta_distr.md)

Determine if x is an initialized beta distribution object as created by
[`create_beta_distr`](https://docs.ropensci.org/beautier/reference/create_beta_distr.md)

## Usage

``` r
is_init_beta_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized beta distribution object

## Value

TRUE if x is an initialized beta distribution object
