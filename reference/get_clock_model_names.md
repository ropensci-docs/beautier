# Get the clock model names

Get the clock model names

## Usage

``` r
get_clock_model_names()
```

## Value

the clock model names

## See also

Use
[create_clock_models](https://docs.ropensci.org/beautier/reference/create_clock_models.md)
to create a list with all clock models

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
check_empty_beautier_folder()

get_clock_model_names()
#> [1] "relaxed_log_normal" "strict"            

check_empty_beautier_folder()
```
