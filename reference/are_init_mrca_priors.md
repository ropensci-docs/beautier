# Determine if x consists out of initialized MRCA priors

Determine if x consists out of initialized MRCA priors

## Usage

``` r
are_init_mrca_priors(x)
```

## Arguments

- x:

  the object to check if it consists out of initialized MRCA priors

## Value

TRUE if x, or all elements of x, are initialized MRCA priors
