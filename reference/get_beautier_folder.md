# Get the path to the [beautier](https://docs.ropensci.org/beautier/reference/beautier-package.md) temporary files folder

Get the path to the
[beautier](https://docs.ropensci.org/beautier/reference/beautier-package.md)
temporary files folder

## Usage

``` r
get_beautier_folder()
```

## Value

the path to the
[beautier](https://docs.ropensci.org/beautier/reference/beautier-package.md)
temporary files folder

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
check_empty_beautier_folder()

get_beautier_folder()
#> [1] "/github/home/.cache/beautier"

check_empty_beautier_folder()
```
