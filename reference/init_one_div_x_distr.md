# Initializes an one-divided-by-x distribution

Initializes an one-divided-by-x distribution

## Usage

``` r
init_one_div_x_distr(one_div_x_distr, distr_id = 0)
```

## Arguments

- one_div_x_distr:

  a one-divided-by-x distribution, using
  [create_one_div_x_distr](https://docs.ropensci.org/beautier/reference/create_one_div_x_distr.md)

- distr_id:

  the first distribution's ID

## Value

an initialized one-divided-by-x distribution
