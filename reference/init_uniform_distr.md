# Initializes a uniform distribution

Initializes a uniform distribution

## Usage

``` r
init_uniform_distr(uniform_distr, distr_id = 0)
```

## Arguments

- uniform_distr:

  a uniform distribution, using
  [create_uniform_distr](https://docs.ropensci.org/beautier/reference/create_uniform_distr.md)

- distr_id:

  the first distribution's ID

## Value

an initialized uniform distribution
