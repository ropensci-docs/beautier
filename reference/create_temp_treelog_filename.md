# Create a filename for a temporary \`treelog\` file

Create a filename for a temporary \`treelog\` file

## Usage

``` r
create_temp_treelog_filename()
```

## Value

a filename for a temporary \`treelog\` file

## See also

use
[create_treelog](https://docs.ropensci.org/beautier/reference/create_treelog.md)
to create a treelog.

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
check_empty_beautier_folder()

create_temp_treelog_filename()
#> [1] "/github/home/.cache/beautier/treelog_5a56693f5f.trees"

check_empty_beautier_folder()
```
