# Get the site models' names

Get the site models' names

## Usage

``` r
get_site_model_names()
```

## Value

the site model names

## See also

Use
[create_site_models](https://docs.ropensci.org/beautier/reference/create_site_models.md)
to get all site models

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
check_empty_beautier_folder()

get_site_model_names()
#> [1] "JC69" "HKY"  "TN93" "GTR" 

check_empty_beautier_folder()
```
