# Check if the `tracelog` has the list elements of a valid `tracelog` object.

Calls `stop` if an element is missing

## Usage

``` r
check_tracelog_names(tracelog)
```

## Arguments

- tracelog:

  a `tracelog`, as created by
  [create_tracelog](https://docs.ropensci.org/beautier/reference/create_tracelog.md)

## Value

nothing

## See also

Use
[create_tracelog](https://docs.ropensci.org/beautier/reference/create_tracelog.md)
to create a valid `tracelog`
