# Internal function

Converts a normal distribution to XML

## Usage

``` r
distr_to_xml_normal(distr, beauti_options)
```

## Arguments

- distr:

  a normal distribution, as created by
  [`create_normal_distr`](https://docs.ropensci.org/beautier/reference/create_normal_distr.md))

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

the distribution as XML text
