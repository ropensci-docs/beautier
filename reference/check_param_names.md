# Check if the `param` has the list elements of a valid `param` object.

Calls `stop` if an element is missing

## Usage

``` r
check_param_names(param)
```

## Arguments

- param:

  a parameter, as can be created by
  [`create_param`](https://docs.ropensci.org/beautier/reference/create_param.md).

## Value

nothing

## See also

Use
[create_param](https://docs.ropensci.org/beautier/reference/create_param.md)
to create a valid `param`
