# Initializes a Coalescent Exponential Population tree prior

Initializes a Coalescent Exponential Population tree prior

## Usage

``` r
init_cep_tree_prior(cep_tree_prior, distr_id, param_id)
```

## Arguments

- cep_tree_prior:

  a Coalescent Exponential Population tree prior, as returned by
  [`create_cep_tree_prior`](https://docs.ropensci.org/beautier/reference/create_cep_tree_prior.md)

- distr_id:

  a distributions' ID

- param_id:

  a parameter's ID

## Value

an initialized Coalescent Exponential Population tree prior
