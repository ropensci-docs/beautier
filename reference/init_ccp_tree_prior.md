# Initializes a Coalescent Constant Population tree prior

Initializes a Coalescent Constant Population tree prior

## Usage

``` r
init_ccp_tree_prior(ccp_tree_prior, distr_id, param_id)
```

## Arguments

- ccp_tree_prior:

  a Coalescent Constant Population tree prior, as returned by
  [`create_ccp_tree_prior`](https://docs.ropensci.org/beautier/reference/create_ccp_tree_prior.md)

- distr_id:

  a distributions' ID

- param_id:

  a parameter's ID

## Value

an initialized Coalescent Constant Population tree prior
