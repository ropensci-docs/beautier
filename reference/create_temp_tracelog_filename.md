# Create a filename for a temporary \`tracelog\` file

Create a filename for a temporary \`tracelog\` file

## Usage

``` r
create_temp_tracelog_filename()
```

## Value

a filename for a temporary \`tracelog\` file

## See also

use
[create_tracelog](https://docs.ropensci.org/beautier/reference/create_tracelog.md)
to create a tracelog.

## Author

Richèl J.C. Bilderbeek

## Examples

``` r
check_empty_beautier_folder()

create_temp_tracelog_filename()
#> [1] "/github/home/.cache/beautier/tracelog_5d22c97df9f.log"

check_empty_beautier_folder()
```
