# Determine if x is an initialized log_normal distribution object as created by [`create_log_normal_distr`](https://docs.ropensci.org/beautier/reference/create_log_normal_distr.md)

Determine if x is an initialized log_normal distribution object as
created by
[`create_log_normal_distr`](https://docs.ropensci.org/beautier/reference/create_log_normal_distr.md)

## Usage

``` r
is_init_log_normal_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized log_normal distribution
  object

## Value

TRUE if x is an initialized log_normal distribution object
