# Determine if x is an initialized uniform distribution object as created by [`create_uniform_distr`](https://docs.ropensci.org/beautier/reference/create_uniform_distr.md)

Determine if x is an initialized uniform distribution object as created
by
[`create_uniform_distr`](https://docs.ropensci.org/beautier/reference/create_uniform_distr.md)

## Usage

``` r
is_init_uniform_distr(x)
```

## Arguments

- x:

  the object to check if it is an initialized uniform distribution
  object

## Value

TRUE if x is an initialized uniform distribution object
