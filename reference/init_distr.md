# Initializes a distribution

Initializes a distribution

## Usage

``` r
init_distr(distr, distr_id = 0, param_id = 0)
```

## Arguments

- distr:

  a distribution, using
  [`create_distr`](https://docs.ropensci.org/beautier/reference/create_distr.md)

- distr_id:

  the first distribution's ID

- param_id:

  the first parameter's ID

## Value

an initialized distribution
