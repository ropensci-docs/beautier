# Check if the tracelog has the list elements with valid values for being a valid tracelog object.

Calls `stop` if a value is invalid

## Usage

``` r
check_tracelog_values(tracelog)
```

## Arguments

- tracelog:

  a `tracelog`, as created by
  [create_tracelog](https://docs.ropensci.org/beautier/reference/create_tracelog.md)

## Value

nothing

## See also

Use
[create_tracelog](https://docs.ropensci.org/beautier/reference/create_tracelog.md)
to create a valid tracelog
