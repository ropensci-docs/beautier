# Check if the `screenlog` has the list elements of a valid `screenlog` object.

Calls `stop` if an element is missing

## Usage

``` r
check_screenlog_names(screenlog)
```

## Arguments

- screenlog:

  a `screenlog`, as created by
  [create_screenlog](https://docs.ropensci.org/beautier/reference/create_screenlog.md)

## Value

nothing

## See also

Use
[create_screenlog](https://docs.ropensci.org/beautier/reference/create_screenlog.md)
to create a valid `screenlog`
