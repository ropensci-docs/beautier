# Determine if x is an initialized Coalescent Bayesian Skyline tree_prior object

Determine if x is an initialized Coalescent Bayesian Skyline tree_prior
object

## Usage

``` r
is_init_cbs_tree_prior(x)
```

## Arguments

- x:

  the object to check if it is an initialized Coalescent Bayesian
  Skyline tree prior object

## Value

TRUE if x is an initialized Coalescent Bayesian Skyline tree prior
object
