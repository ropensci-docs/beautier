# Determine if x consists out of MRCA priors

Determine if x consists out of MRCA priors

## Usage

``` r
are_mrca_priors(mrca_priors)
```

## Arguments

- mrca_priors:

  a list of one or more Most Recent Common Ancestor priors, as returned
  by
  [`create_mrca_prior`](https://docs.ropensci.org/beautier/reference/create_mrca_prior.md)

## Value

TRUE if x, or all elements of x, are MRCA priors. Returns FALSE
otherwise
