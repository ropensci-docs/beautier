# Internal function

Converts a beta distribution to XML

## Usage

``` r
distr_to_xml_beta(distr, beauti_options)
```

## Arguments

- distr:

  a beta distribution, as created by
  [`create_beta_distr`](https://docs.ropensci.org/beautier/reference/create_beta_distr.md))

- beauti_options:

  one BEAUti options object, as returned by
  [`create_beauti_options`](https://docs.ropensci.org/beautier/reference/create_beauti_options.md)

## Value

the distribution as XML text
