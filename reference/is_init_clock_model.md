# Determine if x is an initialized clock_model object, as created by [`create_clock_model`](https://docs.ropensci.org/beautier/reference/create_clock_model.md)

Determine if x is an initialized clock_model object, as created by
[`create_clock_model`](https://docs.ropensci.org/beautier/reference/create_clock_model.md)

## Usage

``` r
is_init_clock_model(x)
```

## Arguments

- x:

  the object to check if it is an initialized clock_models object

## Value

TRUE if x is an initialized clock_model object
