# Determine if x is an initialized Coalescent Exponential Population tree_prior object

Determine if x is an initialized Coalescent Exponential Population
tree_prior object

## Usage

``` r
is_init_cep_tree_prior(x)
```

## Arguments

- x:

  the object to check if it is an initialized Coalescent Exponential
  Population tree prior object

## Value

TRUE if x is an initialized Coalescent Exponential Population tree prior
object
