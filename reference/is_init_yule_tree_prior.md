# Determine if x is an initialized Yule tree_prior object

Determine if x is an initialized Yule tree_prior object

## Usage

``` r
is_init_yule_tree_prior(x)
```

## Arguments

- x:

  the object to check if it is an initialized Yule tree prior object

## Value

TRUE if x is an initialized Yule tree_prior object
