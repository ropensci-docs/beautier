# Check if the `treelog` has the list elements of a valid `treelog` object.

Calls `stop` if an element is missing

## Usage

``` r
check_treelog_names(treelog)
```

## Arguments

- treelog:

  a `treelog`, as created by
  [create_treelog](https://docs.ropensci.org/beautier/reference/create_treelog.md)

## Value

nothing

## See also

Use
[create_treelog](https://docs.ropensci.org/beautier/reference/create_treelog.md)
to create a valid `treelog`
