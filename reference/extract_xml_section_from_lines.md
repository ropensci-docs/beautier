# Get the lines of an XML section, including the section tags

Get the lines of an XML section, including the section tags

## Usage

``` r
extract_xml_section_from_lines(lines, section)
```

## Arguments

- lines:

  lines of the XML text

- section:

  the XML section name

## Value

the section's lines of XML text, including the tags
