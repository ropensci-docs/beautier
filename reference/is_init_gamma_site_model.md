# Determine if x is an initialized gamma site model, as created by [`create_gamma_site_model`](https://docs.ropensci.org/beautier/reference/create_gamma_site_model.md)

Determine if x is an initialized gamma site model, as created by
[`create_gamma_site_model`](https://docs.ropensci.org/beautier/reference/create_gamma_site_model.md)

## Usage

``` r
is_init_gamma_site_model(x)
```

## Arguments

- x:

  the object to check if it is an initialized gamma site_models object

## Value

TRUE if x is an initialized gamma site model
