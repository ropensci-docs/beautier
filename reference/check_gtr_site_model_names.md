# Check if the `gtr_site_model` has the list elements of a valid `gtr_site_model` object.

Calls `stop` if an element is missing

## Usage

``` r
check_gtr_site_model_names(gtr_site_model)
```

## Arguments

- gtr_site_model:

  a GTR site model, as returned by
  [`create_gtr_site_model`](https://docs.ropensci.org/beautier/reference/create_gtr_site_model.md)

## Value

nothing

## See also

Use
[create_gtr_site_model](https://docs.ropensci.org/beautier/reference/create_gtr_site_model.md)
to create a valid `gtr_site_model`
